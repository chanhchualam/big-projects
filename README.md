## ⭐ Dự án nổi bật

### [📦 Quản lý hàng hoá — Kho & Bán hàng](quan-ly-hang-hoa/)
Ứng dụng web quản lý kho và bán hàng (POS) cho cửa hàng nhỏ, chạy hoàn toàn trên Firebase.
- Bán hàng tại quầy, quét mã vạch, in hoá đơn A5 / K80; nhập kho; cảnh báo hàng sắp hết
- **Tồn kho không bao giờ âm** nhờ Firestore transaction; Security Rules khoá dữ liệu theo tài khoản chủ cửa hàng
- Báo cáo doanh thu / lợi nhuận với biểu đồ, xuất Excel và PDF tiếng Việt
- `JavaScript (ES Modules)` `Firebase Auth · Firestore · Hosting` `Bootstrap 5` `Chart.js` `SheetJS` `jsPDF`
- 🔗 https://quan-ly-hang-hoa-doh5v.web.app

### [🪷 Thiền Đường Live Overlay](live-niem-phat/)

- `Node.js` `Express` `Socket.IO` `Canvas 2D` `Web Audio`
