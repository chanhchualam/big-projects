THƯ MỤC ẢNH / ÂM THANH
======================
- background.jpg : ảnh nền chánh điện, khuyến nghị 1080x1920 (dọc 9:16).
                   Chưa có file này thì overlay tự vẽ nền chánh điện dự phòng.
                   Muốn dùng tên/định dạng khác (png, webp) -> sửa "scene.background" trong config.json.
- bgm.mp3        : (tuỳ chọn) nhạc nền lặp. Không có thì dùng nhạc nền tổng hợp nhẹ.
